# Audit 001 remediation

Date: 2026-09-06
Scope: all four findings in [audit 001](audit-001-2026-09-06.md), explicitly approved by the owner. This report closes those findings; it is not a new whole-product accessibility certification.

## Results

- R-25 PASS: supporting text now uses `#8996a5`, measured at 6.38:1 on `#0b0f14` and 5.92:1 on `#121820`, exceeding 4.5:1. The footer uses the same token. Loading animation now affects the grid pseudo-element, leaving explanatory text at full opacity.
- R-03 PASS: selection button, minibar timeline button, density toggle, forecast footer link, record return link, and expanded evidence-status link have minimum 44px hit areas. Browser measurements confirmed 44px heights; the chooser selection button measured 44 × 44px. The miniature chart keeps its original 22px visual scale inside its larger button.
- R-27 PASS: record search has a persistent polite, atomic status region, a visible loading message, result-count feedback, and `aria-busy` on its input. A deferred browser response showed the loading message and busy=true, then the no-match message and busy=false, with focus remaining in the input. The new interaction test also checks successful completion and clearing.
- R-02 PASS: audited rendered strings and metadata use colons, commas, parentheses, or explicit Korean missing-value labels. Missing forecasts display “미발표”; missing evidence displays “기록 없음”. A browser fixture displayed missing today values beside tomorrow's published `0%` and `0mm`. A source-AST regression check covers string/template/JSX text while excluding historical comments.
