# Audit 005 · User journeys and accessibility

September 26, 2026. Audit-only mode. No application fixes applied. Source: `be4120f9ed1f2b38b98cc8d8d058d69d34c0d503`; live production Chromium browser.

1. **HIGH · R-32 · Scoring table keyboard access.** At 390 px, axe 4.12.1 flags `scrollable-region-focusable` on `.btd-table-scroll:nth-child(3)`. The wrappers in `app/behind-the-data/page.tsx:150,204` lack explicit focusability. Add a labelled keyboard-focusable scroll region, visible focus styling, and cross-browser arrow-key verification. Automated finding with source confirmation; physical assistive-technology behavior was not tested.
2. **HIGH · C-4 / antislop-human semantics · Invalid definition list.** `components/local/LocalForecastExperience.tsx:579–594` puts `small` beside `dt/dd` inside definition-list groups. Axe flags `definition-list` (WCAG 1.3.1). Place the supporting copy inside `dd` while preserving layout.
3. **LOW · C-4 / antislop-human navigation · Chooser has no main landmark.** Axe flags `landmark-one-main`, a best-practice rule rather than a claimed WCAG failure. Wrap the active chooser content in a main landmark without nesting it inside the dashboard's existing main.
4. **LOW · R-06 / R-20 · Readability recommendation.** Some supporting labels are 10.88 px in the browser. Consider larger useful labels and a shorter dry-weather headline with its 40% threshold explanation retained nearby. This is a usability judgment, not evidence of contrast or conformance failure. Preserve ADR 0009/0010 chart scales, source attribution and progressive disclosure.
